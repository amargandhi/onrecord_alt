# Reuse and attribution

OnRecord is a new HackSprint project assembled from narrowly selected parts of the author's earlier private/local prototypes. Source repositories remain separate inputs; their histories, credentials, outputs, and private media are not to be copied into this repository.

## Final disclosure rule

Before release, replace “candidate material” with the exact files or functions actually imported, record the import commit in this repository, preserve original notices, and credit every human collaborator. Reuse must be described as reuse; a new wrapper or agent layer does not make earlier code event-built.
